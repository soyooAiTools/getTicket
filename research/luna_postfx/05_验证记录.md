# 验证记录

## 交叉验证 1：官方文档 vs 本地插件

- 官方文档说 `Post Processing = No`
- 本地 `config.json` 只有 `ssao`
- 本地 release notes 强调的是 `URP Render Objects support` 与 `SSAO warning`

结论：一致，没有发现“文档说不支持，但插件已完整支持”的反证。

## 交叉验证 2：官方 CSS Filters vs 本地模板

- 官方 CSS Filters 页面列出 6 个滤镜
- 本地 `filters.pug` 也正好实现了这 6 个滤镜

结论：一致，说明 CSS Filters 是真实产品能力，不是孤立文档描述。

## 交叉验证 3：模板能力 vs 用户最终产物

- 模板 `body.pug` 中 include 了 `filters.pug`
- 但用户最终 HTML 中没有直接检出相关关键字
- 用户最终 HTML 仍保留 `#application-canvas`

结论：
- “模板内有滤镜钩子”不代表“最终产物一定原样保留”
- 但“最终产物有 canvas 挂点”已经足够支撑产物层补丁方案

## Sanity Check

### 能稳定落地的方案
- SSAO
- CSS Filters
- Render Objects 替代效果
- DOM Overlay
- Bridge 注入 JS

### 只能近似替代的方案
- Bloom
- Vignette
- Film Grain
- Chromatic Aberration
- Lens Distortion

### 不建议做的方案
- 完整 URP Volume 移植
- 旧版 Post Processing package 继续保留
- 深改 Luna 核心 runtime

## 备注

本轮没有使用独立子 agent 做二次审校，改用“官方文档 + 本地插件 + 用户样本产物”三路交叉验证。
