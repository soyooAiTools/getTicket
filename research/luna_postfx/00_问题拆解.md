# Unity Luna 未支持后处理扩展调研 - 问题拆解

## 研究目标
判断在 `Unity Playworks / Luna 7.1.0` 中，针对官方未支持的后处理效果，是否能在：

1. 打包前扩展
2. 打包后扩展

实现可控、可交付、可维护的替代方案。

## 研究边界

- 目标平台：Unity Luna / Unity Playworks Plugin 7.1.0
- 输入样本：
  - 插件包：`E:\Download\Soyoo-Luna_7.1.0.zip`
  - 打包产物：`E:\Download\打包后文件.html`
- 重点对象：URP / 后处理 / 运行时 HTML 注入 / JS 注入 / Render Objects / CSS Filters
- 不覆盖：
  - 原生 Unity App 的完整 URP Volume 栈
  - 非 Luna 运行时
  - 广告平台最终二次包装后的特定私有改写逻辑

## 子问题

### Q1. 官方到底支持哪些“后处理”
- 是支持完整 URP Post Processing，还是只支持极少数效果？
- 有没有官方预留的扩展入口？

### Q2. 打包前能否扩展
- 能否在 Unity 工程内，用 Luna 官方支持的方式插入 JS / HTML / Shader 替代方案？
- 哪些效果适合用 Render Objects、材质、UI Overlay、CSS Filters 来替代？

### Q3. 打包后能否扩展
- 最终 HTML 是否存在稳定挂载点？
- 是否能通过补脚本 / DOM Overlay / Canvas CSS Filter 做产物层增强？

### Q4. 哪些效果值得做，哪些不值得做
- 哪些效果能低风险上线
- 哪些效果只能做“近似替代”
- 哪些效果不建议碰
