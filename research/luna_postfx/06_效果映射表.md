# 需求效果映射表

截至本次核验（2026-04-19），以下判断基于：

- Luna 官方文档当前支持矩阵
- 你提供的 `Luna 7.1.0` 插件包本地证据
- 你提供的最终打包产物 HTML 结构

## 总览

| 效果 | Luna 原生直带 | 可替代实现 | 推荐层级 | 结论 |
|---|---|---|---|---|
| Channel Mixer | 否 | CSS Filters + shader 色偏 | 打包前/后 | 可做近似 |
| Chromatic Aberration | 否 | overlay / 边缘色偏 shader | 打包前为主 | 可做近似 |
| Color Curves | 否 | LUT 近似 / CSS Filters / shader 参数 | 打包前为主 | 可做近似 |
| Color Lookup | 否 | LUT 贴图近似 / CSS Filters | 打包前为主 | 可做近似 |
| Depth Of Field | 否 | 分层模糊 / 假景深 | 打包前为主 | 可做弱替代 |
| Film Grain | 否 | overlay noise | 打包前/后 | 很适合替代 |
| Lens Distortion | 否 | 局部扭曲 shader / UI 假透镜 | 打包前为主 | 可做弱替代 |
| Motion Blur | 否 | 残影 / trail / squash | 打包前为主 | 不建议做真效果 |
| Shadows, Midtones, Highlights | 否 | 三段调色近似 | 打包前为主 | 可做近似 |
| Split Toning | 否 | CSS Filters + 双层颜色 overlay | 打包前/后 | 可做近似 |
| White Balance | 否 | CSS Filters + shader 色温参数 | 打包前/后 | 可做近似 |

## 逐项建议

### 1. Channel Mixer
- 原生可用性：不支持
- 推荐做法：
  - 全局方案：`brightness / contrast / saturate / hue-rotate` 组合
  - 精细方案：材质 shader 增加 RGB 通道混合参数
- 建议：
  - 如果只是整体风格统一，用 CSS Filters 即可
  - 如果角色/场景要分开调，必须走 shader

### 2. Chromatic Aberration
- 原生可用性：不支持
- 推荐做法：
  - 边缘 RGB 偏移贴图
  - UI/DOM overlay 做轻微红蓝边缘分离
- 建议：
  - 只做轻度 cinematic 版本
  - 不建议追求真全屏像差

### 3. Color Curves
- 原生可用性：不支持
- 推荐做法：
  - shader 中预设几组曲线近似
  - 用 LUT 贴图或颜色分段映射近似
- 建议：
  - 不做通用编辑器型曲线系统
  - 只做 2-4 套预设风格

### 4. Color Lookup
- 原生可用性：不支持
- 推荐做法：
  - 使用 LUT 风格近似
  - 全局轻量版可用 CSS Filters 模拟
- 建议：
  - 如果只是“冷色/暖色/电影感”，用 CSS Filters 足够
  - 如果追求品牌化调色，可做定制 shader

### 5. Depth Of Field
- 原生可用性：不支持
- 推荐做法：
  - 背景预模糊资源
  - 摄像机分层 / 前后景资源分层
  - 局部 UI 模糊或固定焦点演出
- 建议：
  - 不建议做真实景深
  - 广告里通常只需要“主体清楚、背景更软”

### 6. Film Grain
- 原生可用性：不支持
- 推荐做法：
  - 噪点贴图 overlay
  - DOM noise overlay
- 建议：
  - 这是最值得做替代的一项
  - 成本低、效果稳定、风格提升明显

### 7. Lens Distortion
- 原生可用性：不支持
- 推荐做法：
  - 局部屏幕边缘扭曲
  - UI 透镜遮罩
- 建议：
  - 只做轻度边缘压扁/桶形感
  - 不建议做真实镜头畸变

### 8. Motion Blur
- 原生可用性：不支持
- 推荐做法：
  - 拖尾
  - 残影 sprite
  - 关键动作 squash/stretch
- 建议：
  - 不建议做真全屏 motion blur
  - 性价比最低

### 9. Shadows, Midtones, Highlights
- 原生可用性：不支持
- 推荐做法：
  - shader 做三段调色
  - 或做 2-3 套固定调色 preset
- 建议：
  - 可以做，但别做可视化调色工具
  - 用预设最稳

### 10. Split Toning
- 原生可用性：不支持
- 推荐做法：
  - 阴影冷色 + 高光暖色 overlay
  - shader 或 DOM 颜色叠加
- 建议：
  - 很适合广告风格化
  - 可和 grain / vignette 一起打包成电影感 preset

### 11. White Balance
- 原生可用性：不支持
- 推荐做法：
  - 色温 / 色调两个参数
  - CSS Filters + shader 综合色偏
- 建议：
  - 很适合做成简单全局参数
  - 成本低，收益高

## 实施优先级

### 第一批，最建议先做
- Film Grain
- White Balance
- Split Toning
- Channel Mixer 近似版
- Color Lookup 近似版

### 第二批，可做但要控成本
- Chromatic Aberration
- Shadows / Midtones / Highlights
- Lens Distortion

### 第三批，只建议做广告弱替代
- Depth Of Field
- Motion Blur

## 最终判断

如果你这 11 类都要覆盖，我建议不要以“逐个恢复 Unity 后处理组件”为目标，而是改为做一套 `LunaPostFx Preset System`：

1. 全局滤镜层
2. 叠层特效层
3. 材质替代层
4. Render Objects 层

这样你最终交付的是一套广告表现系统，而不是一堆难维护、还不完全等价的伪 Volume 组件。
